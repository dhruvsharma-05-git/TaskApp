# 📱 TaskApp (Full-Stack React Native Task Manager)

A cross-platform mobile task management application built with **React Native** and powered by a custom **Node.js, Express, and MongoDB** backend. This project implements secure user authentication, token-based sessions, and real-time database integration.

---

## 🚀 Features

* **User Authentication:** Secure sign-up and login functionality with password hashing and JWT (JSON Web Token) authorization.
* **RESTful API Backend:** Node.js & Express server handling user data and business logic.
* **Database Integration:** Persistent data storage using MongoDB and Mongoose.
* **Cross-Platform Ready:** Designed for seamless deployment and testing on Android devices via React Native Metro Bundler.

---

## 🧰 Tech Stack

### Frontend (`TaskApp`)
* **Framework:** React Native (v0.87)
* **Language:** JavaScript / TypeScript
* **Networking:** Fetch API
* **Build Tool:** Metro Bundler

### Backend (`TaskBackend`)
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB / Mongoose
* **Security:** Bcrypt (password hashing), JWT
